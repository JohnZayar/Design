အဝတ်အစား ကြော်ငြာ Prompt Studio

Key မလိုပါ။ Prompt ထုတ်ပြီး Google Flow ထဲ Copy ကူးသုံးပါ။

၁။ အဝတ်အစစ်ပုံ တင်ပါ

ဤနေရာကိုနှိပ်၍ အဝတ်အစစ်ပုံ ရွေးပါ

အဝတ်တစ်ခုတည်း၊ အလင်းကောင်း၊ ခေါက်မထား၊ အရောင်မှန်မှန် ရိုက်ပါ။ ဤပုံကို Flow ထဲ အတူတင်ရမည်ဖြစ်၍ ဖုန်းထဲ သိမ်းထားပါ။

၂။ အဝတ်အချက်အလက်

၃။ ကြော်ငြာပုံစံ

လက်ရှိ trend များ အမြန်ပြောင်းသဖြင့် TikTok/Reels တွင် ကြိုက်သောအကကို ကြည့်ပြီး လှုပ်ရှားပုံကို ဤကွက်တွင် ရေးနိုင်သည်။ သီချင်းကို Flow ထဲ မထည့်ဘဲ TikTok/Reels/CapCut ၏ ခွင့်ပြုထားသောသီချင်းကို Video တင်ချိန် ထည့်ပါ။

Flow ထဲမှာ သုံးနည်း

ပုံ (အဝတ်မပြောင်းအောင်)
  1. Flow ကိုဖွင့်၍ project အသစ်လုပ်ပါ။ Image ဖန်တီးရာ mode ကိုရွေးပါ။
  2. အဝတ်အစစ်ပုံကို reference (Ingredient/ပုံထည့်ရန်) အဖြစ် တင်ပါ။
  3. Prompt ကိုကူးထည့်ပြီး ထုတ်ပါ။ ၂-၄ ပုံထုတ်ခိုင်းပြီး အဝတ်နှင့် အနီးဆုံးကို ရွေးပါ။
  4. မော်ဒယ်ပုံအတွက် အရှေ့ပုံကို အရင်ထုတ်ပါ။ အနောက်/ဘေးပုံတွင် အဝတ်ပုံ နှင့် ထုတ်ပြီးသော အရှေ့ပုံ နှစ်ပုံစလုံး reference တင်ပါ။ လူတူပြီး အဝတ်တူမည်။
Video
  1. အရင်ဆုံး ပုံ Prompt နှင့် ကြော်ငြာပုံကောင်းကောင်း တစ်ပုံထုတ်ပါ။
  2. Flow တွင် ထိုပုံကို Video ၏ Start frame အဖြစ်သုံးပြီး (Frames to Video) Video Prompt ထည့်ပါ။ စာသားမှ Video ထုတ်ခြင်းထက် အဝတ်ပုံစံ ပိုမပြောင်းပါ။
  3. Video တစ်ခုက ၈ စက္ကန့်ခန့်သာ ရပါသည်။ Fast/Lite ဖြင့်စမ်း၊ ကြိုက်မှ Quality သုံးပါ။ Credit ချွေတာနိုင်သည်။

မှတ်ချက်: AI က အဝတ်ကို ၁၀၀% တူအောင် အာမခံမရပါ။ ဝယ်သူထံ မပို့မီ ပုံကို အဝတ်အစစ်နှင့် တိုက်စစ်ပါ (အရောင်၊ ပန်းရိုက်ပုံ၊ ဓာတ်ခွာ/ကြယ်သီး)။ မတူလျှင် ပုံပြန်ထုတ်ပါ။
