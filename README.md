# အဝတ်အစား ကြော်ငြာ Prompt Studio

အဝတ်အစစ်ပုံတင်ပြီး Google Flow ထဲသုံးရန် Prompt ထုတ်ပေးသော web app။ API Key မလိုပါ။

## ဖိုင်
- `index.html` (app တစ်ခုလုံး)
- `README.md`

## GitHub Pages တင်နည်း
1. GitHub တွင် Public repo အသစ်ဖွင့်ပါ။
2. Add file → Upload files ဖြင့် `index.html` နှင့် `README.md` တင်၊ Commit။
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save။
4. `https://YOUR-USERNAME.github.io/REPO-NAME/` တွင် သုံးပါ။

## သုံးနည်း
1. အဝတ်အစစ်ပုံ တင်ပါ၊ ကျား/မ၊ အဝတ်အမျိုးအစား၊ လူပါ/မပါ၊ နောက်ခံ၊ အချိုးရွေးပါ။
2. "ပုံအတွက်" သို့မဟုတ် "Video အတွက်" Prompt ကို Copy လုပ်ပါ။
3. Flow တွင် အဝတ်ပုံကို reference တင်ပြီး Prompt ထည့်ပါ။
4. Video အတွက် ထုတ်ပြီးသော ကြော်ငြာပုံကို Start frame အဖြစ်သုံးပါ။
